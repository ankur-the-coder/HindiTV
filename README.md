# Hindi TV (v0.2)

Android TV / Android 5.0+ IPTV player for iptv-org playlists (Hindi, English, India, or your own .m3u URL).

Remote controls
- List: OK = play, hold OK = menu (favorite / number), 0-9 = jump to numbered channel, hold 1-9 = give focused channel that number
- Player: UP/DOWN = zap, LEFT or OK = channel list drawer, RIGHT or MENU = options, 0-9 = jump to number,
  hold 1-9 = give current channel that number, hold OK = favorite, BACK = close drawer / exit

Build: push to GitHub; .github/workflows/build.yml builds app-debug.apk.
