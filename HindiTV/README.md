# Hindi TV (prototype)

Android TV / Android 5.0+ player for the iptv-org Hindi playlist.
Playlist: https://iptv-org.github.io/iptv/languages/hin.m3u

Remote controls
- List: OK = play, hold OK = add/remove favorite
- Player: UP/DOWN = next/previous channel, hold OK or MENU = favorite, BACK = list

Build: push to GitHub; the Actions workflow in .github/workflows/build.yml builds app-debug.apk.
